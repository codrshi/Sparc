# Sparc — Spend, Plan & Record
Sparc is a personalized expense management web application designed to help users efficiently track, manage, and optimize their financial activities.

Sparc provides following features:
- It enables users to record and categorize expenses.
- It can generate detailed monthly reports visualizing spending patterns through graphs and datasets.
- Users can configure recurring expenses that are automatically tracked each month, set spending limits across categories with proactive notifications, and allocate emergency funds that are systematically deducted from monthly savings.
- An interactive dashboard providing real-time insights into weekly expenditures, upcoming recurring transactions, and financial milestones achieved.
- The platform integrates an AI-powered financial advisor that analyzes spending behavior over selected periods and delivers data-driven financial planning recommendations and optimization strategies.

## Tech Stack
- **Language**: JavaScript
- **Frontend Framework**: React
- **Backend Framework**: Express.js
- **Persistence**: PostgreSQL
- **Reverse Proxy / Web Server**: Nginx
